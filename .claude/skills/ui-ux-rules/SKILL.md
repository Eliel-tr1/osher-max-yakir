# חוקי עיצוב וחוויה

עודכן: 2026-10-19. כל החלטת עיצוב נכתבת כאן, כדי שכל המסכים ייראו כמו מערכת אחת.

## שפה וכיוון
- ממשק בעברית, מימין לשמאל (`dir="rtl"`). מספרים, תאריכים ומיילים נשארים קריאים בתוך טקסט עברי.
- רק מקף רגיל "-", אף פעם לא מקף ארוך.
- תאריכים בפורמט יום/חודש/שנה למשתמש, ISO בקוד.

## צבעים וטיפוגרפיה
(הטוקנים: צבע ראשי, משני, רקע, טקסט, הצלחה, שגיאה. הגופן והגדלים. ייכתב כשייקבע מיתוג.)

|---|---|---|

## רכיבים
(כפתורים, שדות, טבלאות, כרטיסים, הודעות. איך כל אחד נראה ומתי משתמשים בו.)

## מצבים שכל מסך צריך
- ריק: מה רואים כשאין עדיין נתונים, ומה הצעד הבא.
- טעינה: שלד או מחוון, לא מסך לבן.
- שגיאה: מה קרה במילים פשוטות, ומה אפשר לעשות.
- טלפון: כל מסך עובד ברוחב 390 בלי גלילה לצדדים.

## ניסוח
- משפטים קצרים, בגוף שני, בלי מונחים טכניים.
- כפתור אומר מה יקרה: "שמור", "שלח הודעה", לא "אישור".
