# עדכון המסמכים

המסמכים מתעדכנים **באותו קומיט** שמסיים את המשימה, לא אחר כך.

| מה קרה | מה מעדכנים |
|---|---|
| issue הסתיים ודווח | `docs/TIMELINE.md`: שורה תחת התאריך של היום, עם מספר ה-issue. ובראש הקובץ, "איפה הפרויקט עומד". |
| המצב השתנה (משהו עלה לאוויר, משהו נשאר באמצע, נמצאה מלכודת) | `docs/HANDOFF.md` |
| המנהל הכריע בשאלה | `docs/DECISIONS.md`: שורה עם תאריך, שאלה, החלטה ו-issue. וסוגרים את השאלה. |
| סביבה, כתובת, משתנה סביבה, שירות או דרך פריסה השתנו | `docs/ENVIRONMENTS.md` (שמות של משתנים בלבד, אף פעם לא ערכים) |
| נמצא סיכון חדש, או סיכון השתנה | `docs/RISKS.md` |
| השתנו המטרה, הקהל, מה בפנים ומה בחוץ, או תהליך מרכזי | `docs/PROJECT.md` |
| השתנתה צורת הפרויקט או אופן ההרצה | `README.md` |
| נקבע חוק קוד, בדיקה או עיצוב | הסקיל המתאים: `build-rules`, `project-qa`, `ui-ux-rules` |
| נקבע חוק עבודה לסוכנים | `AGENTS.md` |

## חוקים
- תאריכים כתאריכים (2026-10-19), לא "אתמול".
- המצב הנוכחי למעלה, ההיסטוריה למטה.
- אין סודות באף מסמך.
- רק מקף רגיל "-".
- `pos.py audit` מתריע על מסמכים שלא זזו בזמן שהקוד זז.
