# דשבורד אושר מקס: הסבר כללי

עודכן: 2026-10-19

## המטרה
דשבורד שמציג לאושר מקס את הנתונים שכבר נאספים היום בטבלאות גוגל שיטס, במקום אחד, ברור, ומעודכן לבד.
הטבלאות דינמיות: הנתונים בהן משתנים כל הזמן, והדשבורד צריך להראות את המצב העדכני בלי עבודה ידנית.

הצלחה בגרסה 1: דשבורד חי, עם כניסה מאובטחת, שמציג את מספרי המפתח שיוכרעו ב-#4, ומתעדכן תוך כמה דקות מכל שינוי בטבלאות.

## למי
- **אושר מקס**: הצופה העיקרי. (מה בדיוק הוא צריך לראות, ועל איזו החלטה הדשבורד עוזר, נקבע ב-#4.)
- **מי שמעדכן את הטבלאות**: ממשיך לעבוד בגוגל שיטס כמו היום. הדשבורד רק קורא.
- (משתמשים נוספים, אם יש, ייקבעו ב-#6.)

## מה בפנים ומה בחוץ
| בפנים | בחוץ (לעכשיו) |
|---|---|
| קריאה מהטבלאות הקיימות, בהרשאת צפייה בלבד | כתיבה או עריכה של נתונים מתוך הדשבורד |
| מספרי מפתח, גרפים וסינון לפי תקופה | בניית טבלאות או טפסים חדשים לאיסוף נתונים |
| כניסה מאובטחת לרשימת משתמשים | אפליקציה לטלפון (הדשבורד עובד בדפדפן של הטלפון) |
| עברית מימין לשמאל, מחשב וטלפון | התראות בוואטסאפ או במייל (אפשר בגרסה הבאה) |
| הודעה ברורה כשמבנה של טבלה משתנה | |

## התהליכים המרכזיים
1. מישהו מעדכן שורה בטבלת גוגל שיטס, כמו היום.
2. תוך כמה דקות, הדשבורד קורא את הטבלה מחדש ומעדכן את המספרים והגרפים.
3. אושר נכנס לדשבורד עם חשבון הגוגל שלו, רואה את המצב, ומסנן לפי תקופה.
4. אם עמודה שהדשבורד צריך זזה או שינתה שם, הדשבורד מראה הודעה ולא מספר שגוי, והסוכן מקבל את זה בלוג.

## המבנה
ההמלצה, ממתינה להכרעה ב-#5:

```
גוגל שיטס (הטבלאות הקיימות)
   | קריאה בלבד, חשבון שירות
   v
שכבת נתונים: קריאה, בדיקת מבנה, מטמון של כמה דקות
   |
   v
אפליקציית Next.js ב-Vercel: מסכי הדשבורד, כניסה עם גוגל
   |
   v
אושר מקס, בדפדפן במחשב או בטלפון
```

מבנה הטבלאות עצמן ימופה ב-#7 וייכתב ב-docs/DATA.md.

| מטמון | עותק זמני של הנתונים, כדי שהדשבורד יהיה מהיר ולא יקרא מגוגל בכל כניסה. |
